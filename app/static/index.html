Venues

Adding a new venue. Use a distinct name for each property.

Venues appear in the service Venue dropdown. Add venue creates a new record and rejects duplicate names. Use Edit to change or rename an existing venue; Cancel edit returns to adding a venue.

Import venues from CSV

Use the headings Venue name, Address, Company name. Company name must match an existing contact; leave it blank for an unassigned venue. Existing venues are matched by name and updated. An assigned venue must be released before assigning it elsewhere. Importing assigned venues enables Contact has assigned venues for their contacts.

UTF-8 CSV, up to 1 MB and 1000 venue rows. Preview changes before importing.

Contacts

Calendar days after the invoice date. Blank uses the general payment terms; 0 means due on the invoice date.

Example: LEA + 169 produces LEA0169. Include a separator in the prefix if wanted, such as LEA-. This counter advances only when saving an invoice for this contact.

Select venues to reserve for this contact. Unassigned venues remain available to everyone. Unticking this option and saving releases this contact’s venues.

Contacts appear in the Invoice to dropdown. Saving the same name updates its address and assigned contact. Use Edit to change a saved contact.

Business & payment details

Invoice email

Configure SMTP_HOST, SMTP_PORT, SMTP_SECURITY, SMTP_USERNAME, SMTP_PASSWORD and SMTP_FROM in your Unraid container. Use starttls (usually port 587) or ssl (usually port 465). SMTP passwords are kept in container configuration.

Microsoft account

Use your own Microsoft account on this server. A shared app registration can be used on another server with a separate mailbox connection. Sign in only with a code you started here.
